# Embedded vector store + local sentence-embeddings. Both LLM providers (Groq
# primary, Ollama fallback) are called over plain HTTP (httpx), so no SDK.
#
# DISABLED for the small/free cloud deployment: `sentence-transformers` pulls in
# torch, which needs ~500MB resident just to import — more than a 512MB instance
# has in total — and would get the container OOM-killed on the first Discovery
# run (run_discovery.py indexes every report). Both imports are lazy
# (rag/embedder.py, rag/vector_store.py), so leaving them uninstalled is safe:
# the app boots normally and `RAG_ENABLED=false` short-circuits every code path
# that would reach them.
#
# To re-enable on an instance with the RAM: uncomment both lines and set
# RAG_ENABLED=true. Install torch from the CPU index or the image gains ~2.5GB
# of unused CUDA:
#   pip install --extra-index-url https://download.pytorch.org/whl/cpu -r requirements.txt
